## opencomposite-macos 0.1.1

- **Registration the Linux way**: `install.sh` installs the runtime to `~/Library/Application Support/OpenComposite`
  and no longer touches `openvrpaths.vrpath`. WiVRn activates OpenComposite while its server runs and restores the
  file afterwards, as on Linux, so SteamVR is no longer shadowed while WiVRn is off. Needs a WiVRn release from
  orchardxr/wivrn-macos with the OpenVR library setting.
- **`./install.sh --register`** registers the runtime permanently, for use without WiVRn (or with an older WiVRn);
  `./install.sh unregister` takes it out again.
- **Uninstall** removes our vrpath entry if there is one, including the one 0.1.0 wrote. Updating from 0.1.0 keeps
  that entry; run `./install.sh unregister` once to leave registration to WiVRn.
